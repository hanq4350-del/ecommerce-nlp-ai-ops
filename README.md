# 电商评论洞察与运营诊断看板

本项目基于电商评论数据，构建从指标监控、异常识别、NLP 问题归因、运营策略生成到 A/B 实验验证的完整数据分析闭环。项目目标是将非结构化用户评论转化为可量化、可归因、可行动的业务指标，辅助运营人员快速定位用户痛点并制定优化策略。

## 在线体验

Streamlit 在线看板：  
https://ecommerce-review-ai-ops.streamlit.app/

## 项目背景

在电商业务中，用户评论是重要的用户反馈来源，但评论文本通常是非结构化数据，运营人员如果只依赖人工阅读，很难快速发现高频问题和异常类目。因此，本项目围绕电商评论数据搭建运营诊断看板，帮助业务方从评论中识别商品、服务和用户体验问题，并进一步生成可执行的运营优化建议。

## 分析流程

数据清洗 → 指标监控 → 类目异常识别 → NLP 问题归因 → 运营策略生成 → A/B 实验验证 → AI 辅助输出

## 核心功能

- 评论总量、平均评分、推荐率、正向评论占比、负向评论占比等核心指标监控
- 基于平均评分、推荐率和负向评论占比识别异常商品类目
- 基于 NLP 方法提取负向评论高频关键词和差评主题
- 按商品类别对比评论量、平均评分、推荐率和负向评论占比
- 构建差评主题、问题描述、运营策略和客服话术映射表
- 新增 A/B 实验模拟模块，验证运营策略上线后的潜在效果
- 基于评论内容和分析结果，AI 辅助生成详情页优化、客服回复和用户触达建议

## 指标体系

| 指标类型 | 代表指标 | 业务含义 |
|---|---|---|
| 结果指标 | 平均评分、推荐率、正向评论占比、负向评论占比 | 判断整体用户反馈是否健康 |
| 异常指标 | 异常类目数、类目负向评论占比、类目平均评分 | 定位需要优先关注的商品类目 |
| 归因指标 | 负向关键词、差评主题、主题评论数 | 判断用户不满主要集中在哪些问题 |
| 策略指标 | 运营策略、客服话术、A/B 实验指标 | 将分析结果转化为可执行动作 |

## A/B 实验说明

由于个人项目没有真实线上流量，本项目中的 A/B 实验模块为模拟验证模块，用于展示运营策略效果评估方法。

例如，当 NLP 分析发现“尺码问题”是高频差评主题后，可以设计实验：

- A 组：保留原商品详情页
- B 组：增加尺码表、模特试穿信息和尺码推荐说明

通过对比点击率、加购率、支付转化率、尺码相关差评率和退货率，判断优化策略是否具备推广价值。该模块体现的是策略验证思路，而非真实线上实验结果。

## 技术栈

Python、Pandas、Streamlit、Matplotlib、NLP、Prompt Engineering

## 项目价值

本项目的核心价值不是单纯展示评论数据，也不是简单生成 AI 文案，而是将评论文本转化为结构化指标，通过指标监控、异常识别和 NLP 归因定位业务问题，并进一步输出运营策略和实验验证方案，形成从数据分析到运营决策支持的完整闭环。

## 适用场景

- 电商评论分析
- 商品体验问题诊断
- 用户痛点识别
- 运营策略制定
- 客服话术优化
- 活动或详情页优化效果验证
